# Basic Chatbot

A simple rule-based chatbot built in Python, made as part of the CodeAlpha internship.

## About

The chatbot responds to a fixed set of greetings and questions using if-elif logic. It's not powered by AI/ML — just pattern matching on keywords.

## How to Run

```
python chatbot.py
```

## How to Use

Type things like:
- hello
- how are you
- what is your name
- help
- bye (to end the chat)

## Concepts Used

- if-elif statements
- Functions
- Loops
- Input/output handling
