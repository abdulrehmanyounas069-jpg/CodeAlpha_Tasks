# Stock Portfolio Tracker

A simple command-line stock portfolio tracker built in Python, made as part of the CodeAlpha internship.

## About

The user enters stock names and quantities. Prices are hardcoded in a dictionary. The program calculates the total investment and can save the summary to a text file.

## How to Run

```
python stock_tracker.py
```

## How to Use

- Type a stock symbol from the list shown (e.g. AAPL) and press Enter.
- Enter the quantity you want to buy.
- Type `done` when you're finished adding stocks.
- Choose whether to save the summary to `portfolio_summary.txt`.

## Concepts Used

- Dictionaries for storing stock prices
- Input/output handling
- Basic arithmetic
- File handling (optional save feature)
